Order Doesn't Matter,
So Why Does Your Model Care?

A masked-diffusion emoji model vs. frontier LLMs — measuring whether models treat emoji replies as sets or sequences.

Emoji reply benchmark · MDLM (328M) vs GPT-5.5 · Claude-Opus-4.8 · Gemini-3.1-Pro

The premiseAn emoji reply is a bag, not a line

The information in 🎸🎧 and 🎧🎸 is the same. Emoji replies are approximately permutation-invariant — order is mostly convention, not meaning.

  • Autoregressive models factorize p(y)=∏ p(yₜ | y<ₜ) — they must commit to a left-to-right order the data says is meaningless.
  • Masked diffusion trains over random mask orderings — order-agnostic by construction.

Hypothesis: a diffusion specialist should reproduce human emoji behavior — order-free and distribution-matched — better than an AR generalist.

The model under testA tiny emoji-diffusion specialist

Architecture

MDLM (masked discrete diffusion), SUBS parameterization. medium, 328M params, seq-len 64, atomic-emoji vocab.

Task

<eot> text/emoji <eot> emoji <eot> — denoise a fully-masked emoji span into an emoji reply.

Training

Two-phase: semantic scaffolding then reply data, with full permutation augmentation (p=1.0).

Checkpoint

hard1_last — the strongest demo checkpoint, evaluated with a decode-time cap of 3 emoji.

The evalPermutation groups from real reply data

  • Take a held-out emoji prompt (e.g. 🎤🎶🌃).
  • Build 3 permutations of its emoji.
  • Get an emoji reply for each (MDLM sampler / frontier via OpenRouter).
  • Compare replies as order-invariant multisets.
  • 24 groups, identical construction for every model.

Each prompt also carries 6 distinct human replies as the reference distribution.

Metrics (1/2)Stability — does shuffling the prompt change the reply?

perm_stability ↑

mean pairwise Jaccard( replies to permuted prompts )

High = the reply bag is the same no matter how the prompt is ordered.

resample_stability

mean pairwise Jaccard( replies to the same prompt )

The control: how much the reply varies from sampling noise alone.

order_effect ↓  — the real test

order_effect = resample_stability − perm_stability

Isolates the order effect from noise. ≈ 0 → model treats the prompt as an order-free bag. > 0 → order specifically destabilizes the reply.

Metrics (2/2)Fidelity — does the reply match how humans reply?

target_bag_jaccard ↑

Jaccard( reply , human reply )

Multiset overlap with the human emoji reply. Order ignored — only the bag matters.

target_best6_jaccard ↑

max over 6 human replies of Jaccard( reply , ref )

Credits a match to any of the 6 human variants — fairer to generalist models.

All Jaccard is multiset Jaccard over emoji graphemes: Σ min(a,b) / Σ max(a,b) — fully order-invariant.

Finding 1 — decisiveThe specialist wins human fidelity

3–17×

On best-of-6 Jaccard, MDLM scores 0.55 uncapped / 0.86 capped-3 — vs every frontier flagship at 0.05–0.20.

A 328M model trained on the human distribution reproduces human emoji replies 3–17× better than GPT-5.5, Opus-4.8, and Gemini-3.1-Pro. Holds across every run.

Finding 2 — the thesis testThe diffusion model is order-invariant

  • MDLM: order_effect ≈ 0 (0.044 uncapped, −0.054 capped). Shuffling the prompt changes its reply no more than resampling does — it treats emoji as a bag.
  • Opus-4.8 & Gemini-3.1-Pro are clearly order-sensitive: order_effect ≈ 0.18–0.20.
  • GPT-5.5 is also order-invariant (≈ 0) — the strongest AR model has learned it; the other two haven't.

MDLM matches the best frontier model on order-invariance — and a 328M diffusion model gets it structurally, where AR models only reach it at frontier scale.

The resample control was essential: MDLM's raw perm_stability looked low, but that was sampling noise, not order-sensitivity.

Finding 3 — a capability AR can't matchAny-position infilling

Reveal half a reply's emoji, mask the rest, ask the model to fill them in — varying where the revealed emoji sit.

Flat across all three (0.85–0.90). The diffusion model infills regardless of position.

An autoregressive model factorizes left-to-right, so it can only condition on a prefix — suffix and scattered infilling are structurally impossible, not just harder. Examples: 😌🫖☕ → fills 🫖☕/😌🫖 exactly from either end.

The honest claimWhat the data supports

A 328M emoji-diffusion model is order-invariant (order_effect ≈ 0) — matching the best frontier model and beating Opus-4.8 & Gemini-3.1-Pro, which are measurably order-sensitive — while reproducing human emoji replies 3–17× better than GPT-5.5, Opus-4.8, and Gemini-3.1-Pro.

A clean win on both axes, with sampling noise properly controlled.

Limits & next stepsHonest caveats

  • Sample size. 24 prompt groups — widen to the full held-out set for tighter confidence intervals.
  • Noise levels differ. MDLM's diffusion sampler is noisier (resample 0.29–0.56) than the frontier models — order_effect controls for this, but raw stability isn't directly comparable.
  • Semantic credit. Jaccard zeroes near-miss-but-apt replies; an embedding metric would be fairer to all systems.
  • Single checkpoint / task. One emoji model, one reply task — the inductive-bias claim generalizes only as far as this setting.
